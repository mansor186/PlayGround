# ⛏️ Minecraft 2D — ماين كرافت ثنائية الأبعاد (Desktop)

لعبة **Minecraft كاملة 2D لسطح المكتب** بمكتبة `pygame` — بدون أي ملفات خارجية (كل الخامات والأصوات مولّدة إجرائياً بالكود).

## ▶️ التشغيل

```bash
pip install -r minecraft2d/requirements.txt
python -m minecraft2d.main
# أو
python minecraft2d/main.py
```

## ✨ المميزات (Full Game)

- **توليد عوالم إجرائي**: تلال، جبال، صحاري، غابات، ثلوج، كهوف، بحار، حمم، خامات (فحم/حديد/ألماس)، أشجار، زهور
- **28 نوع بلوك**: عشب، تراب، حجر، جذع، أوراق، ألواح، رمل، زجاج، طوب، مشعل مضيء، خامات، بيدروك، ماء، حمم، فرن، صندوق، طاولة صناعة...
- **فيزياء كاملة**: جاذبية، قفز، سباحة، غرق، ضرر سقوط، حمم، جوع، تجدد، أكسجين
- **بقاء Survival + إبداعي Creative** (طيران، كسر فوري) — زر `G` للتبديل، `F` للطيران
- **مخزون 36 خانة + هوت بار 9** مع تكديس 64 وسحب/إفلات (Drag & Drop)
- **صناعة Crafting 3x3**: ألواح، عصي، طاولة، مشاعل، فرن، صندوق، كل الأدوات (خشب/حجر/حديد/ألماس: معول/فأس/مجرفة/سيف)
- **أدوات بمتانة**: المستوى الصحيح مطلوب (الألماس يحتاج حديد...) وإلا لا يسقط الدروب
- **وحوش**: خنزير/غنم (ودودة، تسقط لحم/صوف/تفاح) + زومبي/هيكل (تطاردك ليلاً)
- **دورة ليل/نهار**: شمس/قمر، نجوم، غروب، غيوم، إضاءة ديناميكية حول المشاعل والحمم
- **جسيمات، تشقق التكسير، أصوات إجرائية**، إسقاط والتقاط تلقائي (مغناطيس)
- **حفظ/تحميل**: عوالم مضغوطة + اللاعب + الصندوق (`minecraft2d/saves/`)
- **قوائم**: رئيسية، عالم جديد (اسم/بذرة/وضع)، تحميل، مساعدة، إيقاف، موت، F3 للتصحيح

## 🎮 التحكم

| زر | فعل |
|---|---|
| A/D أو أسهم | حركة |
| Space/W | قفز / سباحة |
| Shift | ركض |
| زر أيسر (ضغط مستمر) | تكسير |
| زر أيمن | بناء / استخدام (فرن/صندوق/طاولة) |
| زر أوسط | نسخ البلوك (Pick) |
| عجلة / 1-9 | الهوت بار |
| E | المخزون + الصناعة |
| Q | إسقاط | R أكل |
| F | طيران (إبداعي) | G وضع اللعب | F3 معلومات | ESC إيقاف |

## 🧪 اختبار سريع بدون شاشة

```bash
SDL_VIDEODRIVER=dummy python -m minecraft2d.main --help 2>&1 | head
python - <<'EOF'
import os; os.environ['SDL_VIDEODRIVER']='dummy'
from minecraft2d.world import World
w = World(seed=123); w.generate()
print('OK', w.spawn, w.height[w.w//2])
EOF
```
