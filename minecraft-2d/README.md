# ⛏️ ماين كرافت 2D — نسخة الكمبيوتر الكاملة (Desktop)

لعبة sandbox ثنائية الأبعاد مستوحاة من Minecraft، مبنية بـ **Python + pygame** وتعمل على
Windows / Linux / Mac بدون إنترنت بعد التثبيت.

## ✨ المميزات (لعبة كاملة فعلاً)

- 🌍 **توليد عوالم إجرائي بالـ Seed**: تلال، كهوف، خامات (فحم/حديد/ذهب/ألماس)،
  4 مناطق حيوية (صحراء / سهول / غابة / ثلج)، أشجار، صبار، ورود
- ⛏️ **حفر ووضع بلوكات**: 23 نوع بلوك (عشب، حجر، خشب، زجاج، طوب، فرن، مشاعل...)
  مع أزمنة تكسير مختلفة حسب الأداة
- 🧰 **أدوات كاملة**: معول/فأس/مجرفة/سيف (خشب → حجر → حديد → ألماس) بسرعات مختلفة
- 🔨 **صنع Crafting**: 19 وصفة (ألواح، عصي، طاولة، أدوات، مشاعل، فرن...)
  بعضها يحتاج طاولة قريبة — تماماً مثل الأصلية
- 🔥 **صهر Smelting**: خام الحديد→سبيكة، رمل→زجاج، حصى→حجر (يحتاج فحم كوقود)
- ❤️ **بقاء Survival**: صحة، جوع، سقوط، تجدد، أكل (لحم خنزير/بقر)
- 👾 **وحوش**: خنازير وأبقار مسالمة + زومبي يطاردك بالليل ويحترق بالنهار
- 🌗 **ليل ونهار**: شمس/قمر/نجوم/غروب + إضاءة مشاعل متوهجة بالليل
- 📦 **دروبات والتقاط**: البلوكات المكسورة تطير وتلتقطها بالمغناطيس
- 💾 **حفظ/تحميل**: عوالم JSON مع Seed واللاعب والوحوش والمخزون
- 🎨 **إبداعي Creative**: موارد لا نهائية + طيران (G)
- ✨ جزيئات، أصوات مولّدة، سحب، Hotbar من 9 خانات

## 🚀 التشغيل

```bash
cd minecraft-2d
pip install -r requirements.txt
python main.py
# أو:
bash run.sh
```

## 🎮 التحكم

| زر | فعل |
|---|---|
| A/D أو ←/→ | حركة |
| Space/W/↑ | قفز |
| زر أيسر (ضغط مطوّل) | تكسير / ضرب وحش |
| زر أيمن | وضع بلوك (أو أكل لو المحدد طعام) |
| 1-9 / عجلة الفأرة | اختيار Hotbar |
| E | المخزون والصنع والصهر |
| F | أكل |
| M | تبديل إبداعي/بقاء |
| G | طيران (إبداعي) |
| F1 | مساعدة |
| F5 | حفظ سريع |
| Esc/P | إيقاف |

### 🎯 بداية سريعة (Survival)
1. اكسر خشب (شجر) بيدك → E → اصنع **ألواح** ثم **عصي** ثم **طاولة**
2. ضع الطاولة، اقترب منها → اصنع **معول خشبي**
3. احفر حجراً وفحماً → اصنع **معول حجري + فرن**
4. اصهر الحديد بالفحم → **معول/سيف حديدي**
5. ابنِ بيتاً وضع **مشاعل** قبل الليل — الزومبي قادم! 🧟

## 📁 الملفات

- `main.py` — حلقة اللعبة، الرسم، الواجهات، الأصوات
- `game_data.py` — البلوكات، الأدوات، الوصفات
- `world_gen.py` — توليد العالم والحفظ
- `entities.py` — فيزياء اللاعب وذكاء الوحوش
- `saves/` — العوالم المحفوظة
